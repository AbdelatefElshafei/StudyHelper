# العدّاد — خطة مذاكرة ذكية

تطبيق ويب مجاني 100% (بدون سيرفر، بدون حساب، بدون أي تكلفة) للمذاكرة العادية مادة بمادة ومحاضرة بمحاضرة. الطالب بيضيف موادّه ومحاضراته بنفسه، وبيحدد هو فين وصل، والخطة اليومية **بتصلّح نفسها كل يوم**. يشتغل أوفلاين كتطبيق على الموبايل (PWA)، وكل البيانات بتتخزن على جهاز الطالب فقط.

## إيه اللي يخليه مختلف؟

| الفكرة | التفاصيل |
|---|---|
| 📍 **إنت اللي بتختار** | مفيش منهج جاهز. بتضيف المواد وتكتب المحاضرات (كل سطر محاضرة، والساعات اختيارية بعد علامة `|`)، وبتحدد **المحاضرة الحالية** في كل مادة بضغطة، والخطة بتبدأ منها. |
| 🔁 **خطة بتصلّح نفسها** | الخطة مش جدول ثابت. كل يوم بتتبني من جديد من «اللي باقي ÷ الأيام اللي باقية». فاتك يوم؟ مفيش تراكم ولا إحساس بالذنب، الباقي بيتوزع تلقائياً. |
| 🧠 **مراجعة متباعدة مدمجة** | أول ما محاضرة تخلص، التطبيق بيجدولها للمراجعة بعد يوم، وأسبوع، وشهر (قابلة للتعديل). المراجعات المتأخرة بتاخد أولوية. |
| 🎯 **موعد اختياري لكل مادة** | لو المادة ليها امتحان أو تسليم، بتحط التاريخ وقبله بـ3 أيام (قابلة للتعديل) اليوم كله بيتحول لمراجعتها، الأضعف الأول. لو مفيش موعد، الخطة بتمشي بسرعة ثابتة (موزعة على 21 يوم افتراضياً). |
| 🚦 **مؤشر السرعة** | أخضر/أصفر/أحمر: المطلوب يومياً مقابل المتاح، برسالة واضحة إيه اللي يتعمل. |
| 📅 **تاريخ الانتهاء المتوقع** | من سرعتك **الفعلية** في آخر 7 أيام: «هتخلص كل المحاضرات يوم كذا، قبل/بعد الامتحان بـ N يوم». ومعاه «لو زودت نص ساعة يومياً هتخلص يوم كذا». |
| ⏱ **بومودورو مدمج** | ابدأ أي مهمة بجلسة 25/5، الشاشة بتفضل منورة، تنبيه صوتي واهتزاز، والدقائق بتتسجل تلقائياً على الدرس. |
| 📤 **تقرير يومي على واتساب** | زرار واحد يبعت ملخص اليوم (المهام، الدقائق، الستريك، العدّ التنازلي) لولي الأمر أو جروب الأصحاب. مفيش سيرفر، مجرد رابط مشاركة. |
| 🗺 **خريطة المواد** | كل محاضرة مربع بلون مستوى إتقانه، فتشوف موادّك كلها في نظرة. |
| 🔗 **مشاركة الخطة** | رابط واحد ينقل المواد والمحاضرات والمواعيد لصاحبك. |


## الملفات

```
index.html              الصفحة الوحيدة
css/style.css           التصميم (موبايل أولاً، RTL، فاتح/داكن)
js/syllabus.js          بيانات ابتدائية فاضية (مفيش منهج جاهز)
js/planner.js           خوارزمية الخطة والمراجعة والسرعة
js/app.js               الواجهة والبومودورو والتقرير
sw.js                   Service Worker للعمل أوفلاين
manifest.webmanifest    بيانات التطبيق للتثبيت على الموبايل
icons/                  الأيقونات
```

بدون أي مكتبات أو أدوات بناء. HTML + CSS + JavaScript خام.

## التشغيل على جهازك

لازم يتفتح من سيرفر (مش بالضغط المباشر على الملف) عشان الـ Service Worker يشتغل:

```bash
python -m http.server 5173
```

ثم افتح `http://localhost:5173`.

## النشر مجاناً على GitHub Pages

التطبيق منشور على: **https://abdelatefelshafei.github.io/StudyHelper/**

النشر تلقائي: أي `git push` على فرع `main` بيشغّل الـ workflow في `.github/workflows/pages.yml` وبينشر الموقع خلال دقيقة (مجاني للمستودعات العامة). في إعدادات الريبو، Pages → Source لازم يكون **GitHub Actions**.

لو عايز تنشر نسختك الخاصة: اعمل Fork أو ريبو جديد، ارفع الملفات، وفعّل Pages بمصدر GitHub Actions. كل المسارات في المشروع نسبية، فالتطبيق بيشتغل من أي مجلد فرعي بدون تعديل.

### بدائل مجانية بنفس السهولة
- **Netlify Drop**: افتح `app.netlify.com/drop` واسحب المجلد كله. رابط فوري.
- **Cloudflare Pages**: اربط المستودع، Build command فاضي، Output directory `/`.

## التثبيت على أندرويد

افتح الرابط في Chrome → القائمة ⋮ → **«إضافة إلى الشاشة الرئيسية»** (أو زرار «تثبيت» اللي بيظهر جوه التطبيق). بعدها بيشتغل أوفلاين بالكامل كتطبيق عادي.

## التحديثات

عدّل الملفات وارفعها. الـ Service Worker بيحمّل الجديد في الخلفية ويظهر في الفتحة اللي بعدها. لو ضفت ملفات جديدة للتطبيق، ضيفها لقائمة `SHELL` في `sw.js` وغيّر رقم `VERSION` عشان الكاش القديم يتمسح.

## الخصوصية

مفيش حساب ولا سيرفر ولا تتبع. كل البيانات في `localStorage` على جهاز الطالب. زرار «تصدير نسخة احتياطية» بيطلع ملف JSON تقدر ترجّعه في أي وقت أو على جهاز تاني.

## أفكار للإصدار الجاي

- بنك أسئلة من ملخصات الطالب (أكمل/اختياري) يتولد تلقائياً.
- تذكير يومي بالإشعارات.
- مقارنة الستريك مع الأصحاب برابط مشترك.
